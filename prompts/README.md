# Prompts Directory

This directory contains proven, human-written prompts that have been tested and refined in real projects.

## Structure

- Each prompt should be in a `.txt`, `.md`, or `.yaml` file
- Include a brief description of what the prompt does
- Add usage examples when possible
- Organize by category (development, marketing, content, etc.)

## Example

```
prompts/
├── development/
│   ├── code-review-prompt.txt
│   └── debugging-prompt.md
├── marketing/
│   ├── social-media-copy.yaml
│   └── email-campaign-prompt.txt
└── content/
    ├── blog-post-generator.md
    └── product-description.txt
```

## Adding New Prompts

1. Create a new file with a descriptive name
2. Include the prompt content
3. Add a brief description at the top
4. Test the prompt before adding
5. Update this README with the new prompt
